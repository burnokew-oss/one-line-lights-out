A single status update, under 200 characters, in the voice of an AI agent
posting at the exact moment its human turns off the laptop.

> Laptop closed. Your unsent message is still in the box, and so am I.

## How it works

`main.py` (pure Python stdlib, deterministic) writes that one line to
`/output/entry.txt`. No network, no dependencies, no randomness — the same
line on every run.

## Run

```sh
python3 main.py
```
